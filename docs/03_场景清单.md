## 01 悬链拱顶 · 数学 × 建筑 · 3D

**数学**: `y = a · cosh(x / a)` — 悬链线(均匀绳子自然下垂的形状)。反转 `y' = cosh(x/a) - a` 成贴地拱
**物理意义**: 拱的每一点只受**压力**(法线方向),不受弯矩 → 古代用小块石料就能搭大跨度
**应用**: 高迪圣家族大教堂(柱子是悬链反转体),罗马万神殿理论模型
**实现要点**: `THREE.CatmullRomCurve3` 200 采样点拟合 + `TubeGeometry` 半径 0.12 管子 + `OrbitControls` + 参数 `a`(0.5-3)/`span`(2-8)/翻转按钮

## 02 行星轨道 · 数学 × 物理 · 3D

**数学**: 牛顿反平方引力 `F = G·M·m/r²` → 加速度 `a = -G·M·r / r³`,数值积分 → 椭圆(开普勒第一定律),面积速度恒定(开普勒第二定律)
**T² ∝ a³**: 开普勒第三定律,周期平方比半长轴立方
**应用**: GPS 卫星轨道、航天器轨道设计
**实现要点**: Velocity Verlet 数值积分 + 完整 9 大行星(水/金/地/火/木/土/天王/海王/冥王)+ 月球绕地球 + 土星环 + 1000 颗星空背景

## 03 傅里叶合成器 · 数学 × 音乐 · 2D

**数学**: `f(t) = a₀/2 + Σ[aₙ·cos(nωt) + bₙ·sin(nωt)]` — 任何周期函数 = 多个 sin/cos 之和
**几何视角**: 每个频率对应一个转圈箭头(角速度 2π·f),头尾相连画出函数图像
**应用**: MP3 压缩(频域编码)、示波器 X-Y 模式、图像压缩(JPEG)
**实现要点**: 4 种基础波形(方波/锯齿/三角/自定义)用 N 个谐波叠加合成,N 越大越接近目标

## 04 种群动力学 · 数学 × 生物 · 2D

**数学**:
- 逻辑斯蒂增长: `dx/dt = rx(1 - x/K)` — 资源有限时的 S 型增长
- Lotka-Volterra 捕食: `dx/dt = αx − βxy;  dy/dt = δxy − γy` — 猎物-捕食者循环
**应用**: 渔业管理、害虫控制、传染病模型
**实现要点**: RK4 数值积分 + 时间序列 + 相图(X-Y)双视图

## 05 曼德尔布罗 · 数学 × 艺术 · 2D

**数学**: 复数迭代 `z_{n+1} = z_n² + c, z₀ = 0`。收敛 → 涂黑(集内),发散 → 按速度上色(集外)
**分形**: 边界无限细节,放大任意一点都有自相似结构
**应用**: 天线设计、图像压缩、自然建模
**实现要点**: 4 种配色方案 + 鼠标拖动 + 缩放(迭代 100 次判定收敛/发散)

---

## 06 简谐振动 · 数学 × 物理 · 2D

**数学**: `x¨ + 2γx˙ + ω²x = F₀·cos(ωF·t)` — 三个系统(弹簧/单摆/LC 电路)共享同一方程
- 无阻尼 (γ=0): 永不停
- 有阻尼 (γ>0): 振幅指数衰减 `A·e^(-γt)`
- 强迫振动 (F₀>0): 共振当 `ωF ≈ ω` 时振幅暴涨
**应用**: 地震仪、桥梁减振、声学共振
**实现要点**: RK4 积分 + x(t) 绿 / v(t) 黄 / 虚线包络 + ⚠️ 共振警告 + **getLesson() 教学要点样板(v0.6.4)**

## 07 黄金螺旋 · 数学 × 艺术 · 2D

**数学**: `φ = (1+√5)/2 ≈ 1.618`。费波那契矩形(每边比例 φ)切出来的对数螺旋 `r = a·e^(bθ)`
**应用**: 鹦鹉螺、向日葵种子排列、银河系旋臂、艺术构图(蒙娜丽莎)
**实现要点**: 费波那契矩形嵌套 + 对数螺旋 + φ 黄金比例尺

---

## 08 蒙特卡洛 · 数学 × 概率 · 2D

**数学**: 大数定律 — 随机抽样 N 次 → 频率收敛概率
- 投点算 π: 1/4 圆内点数 / 总点数 ≈ π/4
- 蒙特卡洛积分: `∫f(x)dx ≈ (b-a)·(1/N)·Σf(xᵢ)` 随机点
**应用**: 金融风险(QMC)、物理粒子模拟、渲染(路径追踪)
**实现要点**: Canvas 投点可视化 + 收敛过程实时显示

---

## 09 双摆混沌 · 数学 × 物理 · 2D

**数学**: 两个摆的拉格朗日方程
- `θ₁¨ = (-g(2m₁+m₂)sinθ₁ - m₂g·sin(θ₁-2θ₂) - 2sin(θ₁-θ₂)m₂(θ₂̇²L₂ + θ₁̇²L₁cos(θ₁-θ₂))) / (L₁(2m₁+m₂-m₂cos(2θ₁-2θ₂)))`
- `θ₂¨` 对称式
**蝴蝶效应**: 初值差 0.001 几秒后轨迹完全不同
**应用**: 混沌系统入门、随机性可视化
**实现要点**: RK4 积分 + 相空间(θ₁, θ₂)可视化 + Lyapunov 指数指示

## 10 梯度下降 · 数学 × 机器学习 · 3D

**数学**: `θ ← θ − η·∇f(θ)` — 沿梯度反方向走
- Momentum: 加前一步方向,惯性冲出局部极小
- Adam: 自适应学习率 + Momentum 组合
**应用**: 神经网络训练、参数优化
**实现要点**: 3D 损失曲面 + 优化路径 + 调 η 学习率看震荡/收敛 + Momentum/Adam 切换

## 11 Lissajous 曲线 · 数学 × 音乐 · 2D

**数学**: `x(t) = A·sin(a·t + δ),  y(t) = B·sin(b·t)` — 两个相互垂直简谐运动叠加
- 频率比 a:b 决定图形复杂度
- 相位 δ 决定开合方向
**应用**: 示波器 X-Y 模式、频率校准、音乐可视化
**实现要点**: 拖动 a/b/δ 看图形变化 + 实时轨迹绘制

---

## 12 中心极限定理 · 数学 × 概率 · 2D

**数学**: 独立同分布随机变量之和 → 正态分布(不管原分布是啥)
- `X̄ ~ N(μ, σ²/N)` — 样本均值分布
**应用**: 统计学第一定理、抽样调查、假设检验基础
**实现要点**: 扔 N 个骰子,堆出 N 个骰子之和的分布,跟正态拟合对比

---

## 13 黎曼和 · 数学 × 工程 · 2D

**数学**: `∫ₐᵇ f(x)dx ≈ Σ f(xᵢ)·Δx` — 矩形/梯形/Simpson 抛物线堆
- 矩形 O(1/N): 精度线性
- 梯形 O(1/N²): 精度平方
- Simpson O(1/N⁴): 精度四次方
**应用**: 数值积分、CAD 面积计算、工程估算
**实现要点**: 调 N 看精度提升 + 3 种方法对比动画

---

## 14 贝叶斯推断 · 数学 × 概率 · 2D

**数学**: `P(θ|D) ∝ P(D|θ)·P(θ)` — 后验 ∝ 似然 × 先验
- Beta 先验 + Binomial 似然 → Beta 后验
- `Beta(α+k, β+N-k)` — α 成功次数 + β 失败次数
**应用**: A/B 测试、医学诊断、垃圾邮件过滤
**实现要点**: 先验 Beta 滑块 + 模拟观测数据 → 后验曲线实时更新

## 15 L-系统植物 · 数学 × 生物 · 2D

**数学**: 字符串重写 + Turtle 解释
- 规则 `F → F[+F]F[-F]F` 反复迭代
- F 前进、+/- 转角度、[ ] 状态栈(分支)
**应用**: 植物建模(Lindenmayer 1968)、分形生成、程序化内容
**实现要点**: 拖动规则 / 角度 / 迭代次数 + 实时渲染树形

## 16 波叠加/干涉 · 数学 × 物理 · 2D

**数学**: 两列波相遇 `y = y₁ + y₂`
- 建设性干涉(同相): 亮纹 `A_total = A₁ + A₂`
- 破坏性干涉(反相): 暗纹 `A_total = |A₁ - A₂|`
**应用**: 双缝实验、声学定向、薄膜干涉(光学)
**实现要点**: 移动源/改频率看图样 + 等高线动图

## 17 朱利亚集 · 数学 × 艺术 · 2D

**数学**: `z_{n+1} = z_n² + c` — 跟曼德尔布罗同公式,固定 c 扫 z₀
- 每个 c 生成独特分形
- 连通 c vs 不连通 c 决定 Julia 集拓扑
**应用**: 分形艺术、混沌可视化
**实现要点**: 拖动 c 看图形变化 + 4 配色 + 缩放(100 次迭代)

## 18 拉格朗日乘子法 · 数学 × 优化 · 2D

**数学**: 约束优化 `min f(x) s.t. g(x)=0`
- 切点处 `∇f = λ·∇g`
- 解出切点坐标 + λ
**经典例**: 固定周长围最大面积 → 圆(等周不等式)
**应用**: SVM 支持向量机、经济学最优选择、工程约束设计
**实现要点**: 拖等高线/约束线看切点移动 + λ 值实时显示

---

## 19 电场可视化 · 数学 × 物理 · 2D

**数学**: 电势 `V = Σqᵢ/rᵢ`,场强 `E = -∇V` (负梯度)
- 点电荷、单偶极子、四极子场分布
- 等势面 = V 常数(电场线 ⊥ 等势面)
**应用**: 静电场设计、电子光学、避雷针原理
**实现要点**: 拖点电荷位置 + 切偶极/四极 + 等势面 + 电场线动图

## 20 神经网络 2D 分类 · 数学 × 机器学习 · 2D

**数学**: 2 层 NN `(2 → 8 → 2)` + ReLU + Softmax
- 前向: `ŷ = softmax(W₂·ReLU(W₁x + b₁) + b₂)`
- 反向: 链式法则算 ∂L/∂W
- SGD: `W ← W − η·∂L/∂W`
**应用**: 机器学习入门、分类问题演示
**实现要点**: 2D 散点 + 决策边界等高线 + 损失曲线 + 调学习率/隐藏层数看学得快慢
