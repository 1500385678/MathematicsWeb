## 01 悬链拱顶 · 数学 × 建筑 · 3D

**数学**: `y = a · cosh(x / a)`  —  悬链线(均匀绳子自然下垂的形状)
**反转**: `y' = a · cosh(x / a) - a`  —  悬链线减去最低点,变成贴地拱
**物理意义**: 拱的每一点只受**压力**(法线方向),不受弯矩 → 古代用小块石料就能搭大跨度
**应用**: 高迪圣家族大教堂(柱子是悬链反转体),罗马万神殿理论模型
**实现要点**:
- `THREE.CatmullRomCurve3` 把 200 个采样点拟合成平滑曲线
- `THREE.TubeGeometry` 把曲线做成半径 0.12 的管子 = 拱体
- `OrbitControls` 鼠标轨道
- 参数 `a`(粗细 0.5-3)+ `span`(跨度 2-8)+ 翻转按钮
- 两端立"墙" BoxGeometry 当支撑

## 02 行星轨道 · 数学 × 物理 · 3D

**数学**: 牛顿反平方引力 `F = G·M·m/r²` → 加速度 `a = -G·M·r / r³`
**轨道**: 数值积分 → 椭圆(开普勒第一定律),面积速度恒定(开普勒第二定律)
**应用**: 卫星轨道设计 · GPS · 哈雷彗星回归预测
**实现要点**:
- Velocity Verlet 积分(`accel(p) = -GM * p / |p|³` * 0.5dt²)
- 太阳固定在椭圆焦点 `(c, 0, 0)`,`c = a·e`
- 初速度 `v = sqrt(GM·(1+e)/(a·(1-e)))`(近日点最快)
- 轨迹用 `BufferGeometry` 动态追加(最多 600 点环形缓冲)
- 速度矢量 `THREE.ArrowHelper` 实时指向
- 虚线椭圆参考线 `LineDashedMaterial`
- 调参:偏心率 e(0-0.85)+ 时间倍率(0.1x-3x)+ 暂停/重置

## 03 傅里叶合成器 · 数学 × 音乐 · 2D

**数学**: 任何周期函数 = 一组 sin/cos 之和 `f(t) = a₀/2 + Σ[aₙ·cos(nωt) + bₙ·sin(nωt)]`
**直觉**: 每个箭头 = 一个转圈矢量,角速度 = 2π·f。所有箭头首尾相连,最终位置画出函数。
**应用**: MP3/JPEG 压缩(只保留前 N 个谐波)· 频谱分析 · 音频合成
**实现要点**:
- 左右分屏:左边画转圈箭头,右边画合成函数
- 各波形系数:
  - **方波** bₖ = 4/(kπ),k 奇数
  - **锯齿波** bₖ = 2·(-1)^(k+1)/(kπ),所有 k
  - **三角波** aₖ = 8·(-1)^((k-1)/2)/(π²k²),k 奇数
  - **脉冲** 类似方波但符号按 sin(kπ/2) 调
- 谐波数 N(1-40)+ 频率(0.5-3Hz)+ 波形选择
- 箭头按振幅降序画(大箭头先画,好看)

## 04 种群动力学 · 数学 × 生物 · 2D

**数学**: Lotka-Volterra 方程
```
dx/dt = αx − βxy   (猎物 x: 独自指数涨,被捕食减)
dy/dt = δxy − γy   (捕食者 y: 有食物繁殖,没食物饿死)
```
**守恒量**: `H = δx − γ·ln(x) + βy − α·ln(y)` 沿轨道守恒 → 相图是闭合曲线
**应用**: 渔业管理(避免过度捕捞)· 害虫防治 · 生态保护
**实现要点**:
- RK4 数值积分(比欧拉稳 4 倍)
- 每帧 4 步 → 实时但不失真
- 上半屏:时间序列(绿 x 红 y),最近 60 时间单位
- 下半屏:相图(蓝色闭合曲线 + 黄色当前位置)
- 理论平衡点 `(γ/δ, α/β)` 标虚线十字
- 调 α/β/δ/γ(0.1-2.0)+ 重置

## 05 曼德尔布罗 · 数学 × 艺术 · 2D

**数学**: 复数迭代 `z_{n+1} = z_n² + c, z₀ = 0`
**判定**: `|z| > 2` 一定发散 → 在第 n 步逃逸 → 涂色 n/iter 灰度
**几何**: 集内涂黑,集外按逃逸速度上色。**边界无限自相似**。
**应用**: 天线设计(分形天线)· 图像压缩(分形编码)· 金融市场模型
**实现要点**:
- 低分辨率渲染(画布 0.25x 屏幕宽,4x 加速),`image-rendering: pixelated` 拉伸
- `mandelbrot(cRe, cIm, maxIter)` 纯 JS,O(N·M·iter) 复杂度
- 4 配色:海洋(蓝绿)/ 火焰(红黄)/ 灰度 / 彩虹(HSV)
- 鼠标拖动 + 滚轮缩放(以鼠标位置为锚)
- 🎬 缩放演示:从全貌缓动到 seahorse valley `(−0.745, 0.113)`

## 06 简谐振动 · 数学 × 物理 · 2D

**数学**: `x(t) = A · cos(ωt + φ)` · 微分方程 `x¨ + ω²x = 0`
**三件套**:
- A 振幅
- ω 角频率(周期 T = 2π/ω)
- φ 相位(初相位)
**三个系统,同一公式**:
- 弹簧 ω = √(k/m)
- 单摆 ω = √(g/L)(小角度近似)
- LC 电路 ω = 1/√(LC)
**应用**: 地震仪 · 振荡电路 · 声波 · 建筑抗震
**实现要点**:
- 上半屏:三选一系统可视化(弹簧/单摆/LC 电路)
- 下半屏:x(t) 绿 + v(t) 黄 时间曲线,最近 20 时间单位
- 调 A(0.1-1.5)+ ω(0.3-3)+ φ(0-2π)+ 系统切换
- 速度 `v = -Aω·sin(ωt + φ)`,x 和 v 永远差 90° 相位
