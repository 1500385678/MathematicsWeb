## 范式细节

### 动态 import + 顶层 await(沿用 three.jsWeb)

```js
// index.html L96-108
const V = window.MATHW_V;
const [
  { initViewer, SCENES },
  { LLMClient, loadLLMConfig },
  { LLMMock },
] = await Promise.all([
  import(`./viewer/viewer.js?v=${V}`),
  import(`./kernel/03_llm-client.js?v=${V}`),
  import(`./mock/01_llm-mock.js?v=${V}`),
]);
```

**好处**: 改 `window.MATHW_V` 一处全员生效,不漏改。预加载扫描器抓不到 dynamic import 的 ?v=,但浏览器仍会 prefetch,性能损失微小。

### 场景独立加载(失败兜底)

```js
// viewer.js switchScene
try {
  const mod = await scene.loader();
  const factory = mod.default || mod.createScene || mod.initScene;
  if (typeof factory !== 'function') {
    throw new Error(`场景 ${sceneId} 没导出 default/createScene/initScene 函数`);
  }
  const instance = factory(canvasHost, { aiPanel });
  // ...
} catch (e) {
  aiPanel.appendSystem(`❌ 场景「${scene.title}」加载失败: ${e.message}`);
  // 不 throw,viewer 继续运行,用户可以切其他场景
}
```

### AI 上下文传递

```js
// viewer.js switchScene
viewer.aiPanel.setActiveScene(scene, instance);  // 传 SCENES 项 + 场景实例

// 02_ai-panel.js _buildSceneContext()
_buildSceneContext() {
  if (!this.activeScene) return null;
  let formula = '';
  if (this.activeInstance && typeof this.activeInstance.getFormula === 'function') {
    try { formula = this.activeInstance.getFormula() || ''; } catch (_) {}
  }
  return { title: this.activeScene.title, domain: this.activeScene.domain, formula };
}
```

## 部署视图

v0.1.0 范围:**纯前端**,无后端。

```
浏览器(任意设备)
  ↓
本地 http server
  ↓
静态资源(vendor/three, 所有 .js, .css, .html)
```

v0.5+ 才考虑:
- FastAPI 后端(场景参数云同步)
- 用户系统
- 协作(场景评论/分享)

## 沿用 from 兄弟项目

- **three.jsWeb**: 入口范式 + 动态 import + 顶层 await + 窗口版本 + ?v= 串号 + 暗色主题 + 错误兜底
- **canvasweb**: AI 助手是标配 + tokens.css 体系 + 中文文档
- **OrangeSu** (working dir): 路径在 `_Lib` 体系

## 不沿用

- three.jsWeb 的协作(Yjs) / 评论 Pin — v0.1 数学场景不需要
- canvasweb 的多画布 DB 切换 — v0.1 场景间切换在 viewer 层就够
- canvasweb 的图片库 / 视频 / 文 / 声 / 乐 — v0.1 纯数学,后续可加"AI 生成示意图"
