## v0.1.0 · 2026-08-21

### 已修复

#### fourier-synth `cy` const 不能 +=

**症状**: Chrome console 报 `Uncaught TypeError: Assignment to constant variable.` at line 192
**原因**: `const cy = H * 0.5` 后面用 `cy += dy` 累加箭头位置
**修复**: `const cy` → `let cy`(配套 `let cx` 已对)
**预防**:
- 累加器永远用 `let`
- 如果函数体内要反复改,`let` 起手

### 设计决策(留底)

#### 为什么目录沿用 three.jsWeb 不沿用 canvasweb?

- three.jsWeb 是**纯前端 + 多模块** → MathematicsWeb 同架构
- canvasweb 是**前端 + Python 后端** → MathematicsWeb v0.1 不上后端
- 选范式母版选 three.jsWeb 更对路

#### 为什么用 6 个场景不是更多?

- v0.1 是 MVP,核心是把"6 场景做扎实"而不是"做 12 场景做糙"
- 每个场景平均 200-300 行,6 个 ≈ 1500 行可控
- v0.5 再扩到 12-15 个场景

#### 为什么 AI mock 不上 RAG?

- v0.1 mock 走"场景关键词 → 预设回复",6 场景足够
- 真 LLM 直接拼上下文(场景标题 + 域 + 公式)也够用,不需要向量库
- 后续 RAG 是为"100+ 场景"准备的

#### 为什么 3D 用 three.js 不上 React Three Fiber?

- 沿用 three.jsWeb 范式(原生 three.js + importmap)
- R3F 引入 React + bundler → 破"零构建"原则
- 场景规模小,直接 three.js API 反而简洁
